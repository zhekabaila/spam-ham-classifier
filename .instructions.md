# Spam/Ham Classifier — Project Instructions

This document defines the structure, standards, and workflow for the spam/ham classifier project.

## 📋 Project Overview

**Purpose**: Build a machine learning system that classifies Indonesian text messages as spam or ham using TF-IDF feature extraction and multiple ML algorithms.

**Dataset Structure**:

- Field 1: `kategori` → values: `"spam"` or `"ham"`
- Field 2: `pesan` → text content of the message

## 🔧 Python Modules

### `src/preprocessor.py`

**Purpose**: Text preprocessing and cleaning for Indonesian text.

**Key Functions**:

- `clean_text(text: str) -> str`: Lowercase, remove URLs/numbers/punctuation, normalize spaces
- `remove_stopwords(text: str, language='indonesian') -> str`: Remove stopwords (supports Indonesian and English)
- `preprocess(text: str, remove_stop=True) -> str`: Full preprocessing pipeline

**Language Configuration**:

- Default: `language='indonesian'` (for Indonesian datasets)
- For English: Change to `language='english'`

### `src/predictor.py`

**Purpose**: Inference module for making predictions on new messages.

**Main Class**: `SpamHamPredictor`

- `__init__(model_path)`: Load trained model from disk
- `predict(text: str) -> dict`: Predict single message, returns dict with:
  - `teks_asli`: Original text
  - `teks_diproses`: Preprocessed text
  - `prediksi`: Classification result ('spam' or 'ham')
  - `probabilitas`: Dict with per-class probabilities (%)
  - `keyakinan`: Confidence percentage (%)
- `predict_batch(texts: list) -> list`: Predict multiple messages
- `display_result(result: dict)`: Pretty-print results with progress bars

## 📓 Notebook Execution Sequence (Mandatory Order)

### 1️⃣ `notebooks/01_eda.ipynb` — Exploratory Data Analysis

**Steps**:

1. Load `data/dataset.csv`
2. Check for missing values and duplicates → clean data
3. Analyze label distribution (bar + pie charts)
4. Analyze message length statistics (character count + word count)
5. Apply preprocessing to all messages
6. Save cleaned dataset → `data/dataset_clean.csv`

**Output Files**: `distribusi_label.png`, `distribusi_panjang.png`

### 2️⃣ `notebooks/02_training.ipynb` — Model Training

**Steps**:

1. Load `data/dataset_clean.csv`
2. Train-test split (80-20, stratified)
3. Define 3 pipeline models:
   - Naive Bayes (MultinomialNB, α=0.1)
   - Logistic Regression (max_iter=1000, C=1.0)
   - Linear SVM with Calibration (max_iter=2000, C=1.0)
4. TF-IDF Vectorizer config:
   - `max_features=10000`
   - `ngram_range=(1, 2)` (unigram + bigram)
   - `min_df=2`
   - `sublinear_tf=True`
5. Cross-validation (5-fold stratified) + final evaluation
6. Select best model by CV F1-Macro score
7. Save: `spam_ham_model.pkl` + `model_info.json`

**Output Files**: `confusion_matrix.png`

### 3️⃣ `notebooks/03_prediction.ipynb` — Prediction Interface

**Steps**:

1. Load trained model using `SpamHamPredictor`
2. Single message prediction (example text)
3. Batch prediction (test with 5 example messages)
4. Interactive function `cek_pesan()` for user input

**No file outputs** (purely interactive)

## 🔄 Workflow Rules

1. **Execute notebooks in order**: 01 → 02 → 03. Do NOT skip or reorder.
2. **Dataset columns**: Must be exactly named `kategori` and `pesan`. If different, rename on load.
3. **Language setting**: If dataset is not Indonesian, update `preprocessor.py`:
   - Change `language='indonesian'` → `language='english'` in `remove_stopwords()`
4. **Model retraining**: Always use the same hyperparameters and feature extraction config.
5. **Model selection**: Choose model with highest CV F1-Macro score (not test accuracy alone).

## 🎯 Usage Example

```python
from src.predictor import SpamHamPredictor

# Initialize
predictor = SpamHamPredictor(model_path='models/spam_ham_model.pkl')

# Single prediction
result = predictor.predict("Selamat Anda menang hadiah 1 juta rupiah!")
predictor.display_result(result)

# Batch prediction
messages = ["msg1", "msg2", "msg3"]
results = predictor.predict_batch(messages)
```

## 🚨 Constraints & Assumptions

1. **Dataset size**: Minimum ~1000 messages recommended
2. **Class balance**: Assumes spam/ham split is reasonably balanced (if imbalanced, adjust `stratify=y` in split)
3. **Language**: Preprocessing optimized for Indonesian; adapt stopwords for other languages
4. **Encoding**: CSV must be UTF-8 encoded to handle special characters
5. **Model path**: Always relative to notebook location (`../models/`)
